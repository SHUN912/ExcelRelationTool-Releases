# ExcelRelationTool

用于应收整理、营收统计、交车锁车核查、经营报表、区域汇报及周度经营简报更新的 Excel 桌面工具，提供 Windows 和 macOS 安装包。

本仓库用于发布正式安装包、版本说明及客户端更新信息。业务公共资料、用户模板与可编辑映射由使用者维护，通过软件内的配置共享功能交换。

**[下载正式版](https://github.com/SHUN912/ExcelRelationTool-Releases/releases/latest)** · **[历史版本](https://github.com/SHUN912/ExcelRelationTool-Releases/releases)** 


## 功能一览

| 功能 | 主要用途 |
| --- | --- |
| **一 · 应收报表** | 合并账单与其他费用数据，填写分类、区域、大区、类型、应收月份、账龄等字段，生成“总表”“汇报”，另存自营门店大区 TOP11 文件。支持指定账单字段值及其他费用部分支付余额补充。 |
| **二 · 应收分类报表** | 根据应收数据填写“各项类型”“整体”“经销商”模板，保留模板公式，并将填写完成的模板工作表加入输入报表末尾。 |
| **三 · 营收数据统计报表** | 整理应收、付款、调账与关闭数据，填写整体、自营门店分区域、经销商分区域、经销商类型与整体类型、目标与实际营收等报表。 |
| **四 · 每日交车锁车检查情况** | 根据交车表及锁车检查表生成核查结果。支持连续日期交车数据按天处理，保留每日结果和中间文件。 |
| **五 · 经营报表更新** | 整理车辆明细、交车、收车数据，更新经营情况表，保留处理后的明细与中间结果。 |
| **六 · 区域汇报底稿** | 根据经营及车辆数据更新区域汇报底稿；支持仅更新逾期应收，或仅更新平均成交单价、平均在租单价。 |
| **七 · 周度经营简报更新** | 根据区域运营日报填写全国、自营门店、经销商、行业客户等版块的实际数据，保留模板中由用户维护的目标及上月实际数据。 |

## 下载与安装

前往 **[Releases](https://github.com/SHUN912/ExcelRelationTool-Releases/releases)**，选择目标版本下对应平台的安装包。

| 平台 | 文件 | 安装方式 |
| --- | --- | --- |
| Windows | `.exe` 安装程序 | 按安装向导完成安装或升级。 |
| macOS · Apple Silicon | `.dmg` 安装映像 | 打开 DMG，将应用拖入“应用程序”；升级时替换原应用。 |

- 正式安装包包含所需 Python 运行依赖，无需自行安装 Python。
- 涉及 Excel 联动的功能，需要安装桌面版 Microsoft Excel；网页版 Office 不能替代本地 Excel。
- 系统最低版本及架构要求以对应 Release 为准。Mac `arm64` 安装包用于 Apple Silicon，不作为 Intel Mac 安装包使用。

## 首次使用

1. **准备配置。** 导入内部共享配置包，或自行维护所需公共资料、模板与映射。
2. **选择功能并上传文件。** 可通过选择文件、拖拽或粘贴上传；按界面提示检查文件识别结果。
3. **核对日期与输出位置。** 文件名日期会参与业务日期识别和输出命名，请勿随意删除或更改日期标记。
4. **开始处理。** 查看处理步骤和运行日志，完成后打开输出文件夹核对结果。
5. **处理待检查项。** 若提示字段无法填写，按待检查清单修正来源数据或映射，再重新运行对应功能。

正式包不预置用户业务公共资料、用户维护的模板、可编辑映射及账单指定字段值。**功能四随程序提供的固定内置模板仍会保留。** 软件升级与用户配置维护分开进行，已有设置不会被强制替换为出厂业务配置。

## 配置共享（导入 / 导出）

配置共享用于将一套已维护好的模板、公共资料及可编辑映射交给其他使用者。

### 导出方

1. 打开“配置共享（导入/导出）”。
2. 勾选要分享的项目，检查内容后导出 ZIP。
3. 将生成的共享包发送给接收方。文件名自动包含分享范围、项目数量与导出时间，不包含导出人。

### 接收方

1. 打开配置共享，选择共享包导入。
2. 预览包内内容及本机内容，按需查看映射差异。
3. 勾选需要更新的项目，确认后导入。软件会先备份被替换的本机文件，支持恢复上次导入。

- 配置是否相同按内容校验判断，不只比较文件名。
- 支持该修复的版本允许在本机映射尚未配置时导入合法共享包，无需先随意新增映射。
- 个人路径、业务输入输出、运行日志、月度确认状态和“为账单指定字段值”不参与共享。
- 功能六的底稿 Sheet 对应由软件自动获取，不作为共享配置项。
- 请直接选择软件生成的 ZIP；不要手工修改包内文件或重新压缩，以免破坏校验。

若提示配置结构无效，请确认双方使用的版本支持该共享格式，并提供报错及共享包供维护人员检查。

## 应收与营收流程

常用顺序为 **功能一 → 功能二 → 功能三**。

### 功能一：准备输入

| 输入 | 要求 |
| --- | --- |
| 账单报表 | 文件名以“账单报表”开头，支持多文件合并。 |
| 其他费用表 | 文件名以“其他费用合同数据”开头，支持多文件合并。 |
| 在租表 | 文件名以“在租”开头，包含明确、有效的 `YYMMDD` 或 `YYYYMMDD` 日期，例如 `在租261031.xlsx`。 |
| 其他费用部分支付表（选填） | 文件名包含“其他费用部分支付”，可以带备注，也可以不带时间戳。需有“账单编号”“未核销余额”字段。 |
| 公共资料 | 大客户表、应收底稿、经销商清单从左侧公共资料统一读取。 |

其他费用账单按“账单编号”匹配部分支付表：命中使用补充表中的“未核销余额”，未命中仍使用其他费用表的“优惠后金额”；余额为 `0` 也有效。部分支付表独有的账单不会因此新增到应收结果中。

支持独立匹配步骤的版本会保存匹配后的完整其他费用表及仅含命中账单的明细，供核查替换前金额与余额来源。

输出包括应收报表及独立的 `应收MMDDTOP11.xlsx`。TOP11 从“汇报”数据生成，按自营门店大区展示客户排行及费用汇总；`MMDD` 取自在租表日期。

### 功能二：维护月度模板

- **整体模板：** 更新本月着陆道及上月月底数字。
- **各项类型模板：** 更新上月月底数字。
- **经销商模板：** 无需每月更新。

模板公式计算的合计列应保留公式。模板布局发生变化时，请确认对应版本支持新的填写区域。

### 功能三：选择来源

可自行上传本次应收报表，也可使用**当前软件会话中功能一或功能二最近一次成功运行产生的有效应收输出**。仅选择输入文件不会改变这一来源。

营收模板由用户维护。文件名可带日期和备注，但需保留软件要求的识别文字；同一种模板应只保留一份有效候选文件。当前类型模板名称为“营收模板（分经销商类型与整体类型）”，对应输出工作表为“经销商类型与整体类型”。

## 经营与区域汇报流程

常用顺序为 **功能五 → 功能六**。也可按界面要求自行上传所需文件。

功能六支持以下输入组合，局部更新时只填写对应版块：

| 模式 | 输入 | 填写范围 |
| --- | --- | --- |
| 完整更新 | 按界面准备上月区域汇报底稿、经营情况表及所需车辆、交车、收车等数据 | 对应版本支持的完整汇报版块。 |
| 仅逾期应收 | 一个应收报表及一个上月区域汇报底稿 | “逾期应收（万）”中的租金应收、其他费用应收。 |
| 仅两个单价版块 | 一个处理后的车辆明细表、一个处理后的交车表及一个上月区域汇报底稿 | 平均成交单价、平均在租单价。 |

门店区域发生变化时，请同步维护功能一的区域与签约门店映射，并检查功能六的区域与底稿 Sheet 对应关系。

## 周度经营简报

功能七独立运行，无需先执行前六个功能。

- 上传一份文件名包含“运营日报”的区域运营日报，并保留有效日期。
- 模板文件名包含“周度经营简报模板”；同一目录只保留本次使用的一份。
- 月初按提醒维护模板中的目标及上月实际数据。
- 软件填写各版块实际数据及对应日期；行业客户按运营组织类型识别。

## 检查更新与配置保留

正式版通过“检查更新”查看已发布版本，按提示确认、下载、校验并安装，也可以从 Releases 手动下载安装包。

更新用于替换程序代码，不会自动更新用户维护的月度模板，也不会自动重新处理已有业务文件。覆盖安装时保留已有用户设置；导入共享配置时，才按所选项目更新对应内容并备份原文件。

如需回退，请先备份当前配置和输出，再从历史 Release 获取对应版本。新旧版本的字段与业务规则可能不同，应先核对版本说明。

## 输出与问题反馈

各功能保留最终结果、相应中间文件和运行日志，具体目录以输出设置及完成提示为准。

反馈问题时，请提供：

- 软件版本、操作系统和使用的功能；
- 完整报错截图及本次运行日志；
- 预期结果与实际结果的具体差异；
- 必要时提供脱敏样例；配置共享问题可提供原共享包供维护人员私下核查。

**请勿在公开 Issue 中上传未脱敏的客户、合同、账单、车架号、车牌及内部模板或配置共享包。**
